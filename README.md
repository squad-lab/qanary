# QCodes Utilities
## 🚧 Under Construction 🚧
Implements measurements and replaces QCoDeS for measurements. The package is still under development and is not ready for production use.

## Installation
This pip package has only been tested with `python>=3.9`. Please make sure to update your python installation before going on with installation. It is also always a good idea to keep `pip` and `setuptools` updated to prevent arbitrary install issues. For the full list of app dependencies, check `requirements.txt`. Separate `venv` testing environment is suggested while the package is in production. 

```
pip install git+ssh://git@git.squad-lab.org/squad-lab/qcutils.git
```
This should install the app, and you should be ready to go.
